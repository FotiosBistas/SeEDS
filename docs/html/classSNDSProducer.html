Detailed Description

NDN producer that advertises names, serves Interests, proxies to an HTTP broker, and maintains a resilient, versioned in-memory state.

Responsibilities:

  • Registers Interest filters for IDs, scopes, liveness, state, per-type names, and registry files.
  • Parses incoming Interests and dispatches to handlers (by-ID/by-TYPE fetch, temporal query, version metafile, and resilience endpoints: is_alive/meta/snapshot/patch).
  • Maintains a type→IDs registry, subscription maps (by ID and by TYPE), and an announcement set, emitting user-provided callbacks (RegistryEvents) on changes.
  • Proxies content retrieval to an HTTP Broker (e.g., /get, /temporal-query, /state, /dump, /copy, /add).
  • Keeps a bounded broker “journal” for rehydration/mirroring and can replay it on failover or restart.
  • Optionally runs a resilience IPC server to receive snapshots/patches/role changes and tracks PRIMARY/SECONDARY role in an internal snds_resilience::Store.

Lifecycle:

  • Construction initializes the store with a canonical JSON layout (types/subscribers/announcements/broker), sets an initial resilience role (PRIMARY if IPC is disabled; SECONDARY otherwise), and seeds the in-memory type registry with registryType. It does not start threads or register NDN filters.
  • Call init() to register prefixes, install event hooks, optionally start the IPC server, seed from the Broker dump, and enter the event loop (processing NDN events and intra-queue messages).

Threading/Concurrency:

  • The main NDN work runs in the init() loop via ndn-cxx Face event processing.
  • The resilience IPC server (if enabled) runs on a separate thread and modifies the store via well-scoped methods; atomic flags coordinate role and replay ticks.
  • The registry/subscription/announcement containers are not inherently thread-safe; they are intended to be mutated on the producer’s event thread. Synchronize externally if accessed from other threads.

Ownership:

  • Inherits logging, Face, KeyChain, and configuration from ServiceBase.
  • Does not take ownership of external services beyond what ServiceBase manages.

◆ init()

void SNDSProducer::init ( )
virtual

Initialize and run the SNDSProducer main loop.

Sets up NDN interest filters (ID, scope, liveness, state, per-type and registry files), installs event hooks, optionally starts the resilience IPC server, seeds the local broker from a dump, and then enters the event loop. While running, the producer processes NDN events and intra-queue messages (e.g., temporal query ads/requests, by-ID ads).

Behavior details:

  • If promoted to PRIMARY at runtime, the IPC listener is stopped.
  • When SECONDARY and a rehydrate tick is set, broker journal entries are replayed.
  • Successful prefix registrations are recorded via onRegisterSuccess().
Note
Exits when running becomes false. May create a default identity in the PIB if none exists.

Reimplemented from ServiceBase.
