Detailed Description

Represents an intra-service message with content, type, sender, and optional parameters.

Carries two bodies (message and payload), three enums (message kind, sender role, HTTP verb), and a generated set of optional parameters defined by QUERY_PARAM_LIST. Includes helpers to infer message kind, pack/unpack parameters, and pretty-print for debugging.

◆ infer_type_from_params()

void snds_intra_message::SNDS_INTRA_MESSAGE::infer_type_from_params ( )
inline

Decide type based on current http_type and present parameters.

GET rules

  • id + is_subscription=true → BY_ID_SUBSCRIPTION
  • type + is_subscription → BY_TYPE_SUBSCRIPTION
  • date + timeframe → TEMPORAL_QUERY_REQUEST
  • type → GET_BY_TYPE_REQUEST
  • id → GET_BY_ID_REQUEST
  • (else) → GENERIC

POST rules

  • date → TEMPORAL_QUERY_ADVERTISEMENT
  • id + type → BY_ID_AND_TYPE_ADVERTISEMENT
  • id → BY_ID_ADVERTISEMENT
  • type → BY_TYPE_ADVERTISEMENT
  • (else) → GENERIC
