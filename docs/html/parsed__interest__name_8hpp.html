Detailed Description

Utilities to model and parse SNDS-style NDN Interest names.

This header provides:

  • A taxonomy of Interest “command” components (e.g., temporalQuery, version) via the INTEREST_MESSAGE_TYPE enum and string table.
  • A lightweight value type (parsed_interest_name::ParsedInterestName) that holds a decomposed Interest name (prefix, name, command, params).
  • Helpers to build, parse, and serialize Interest names and query fragments, including URL encode/decode for parameters.

Naming layout (conceptual examples):

  • /SNDS/<name>/<params...>
  • /SNDS/<name>/temporalQuery:date=<val>&timeframe=<val>&count=<val>
  • /SNDS/<name>/version:date=<val>
