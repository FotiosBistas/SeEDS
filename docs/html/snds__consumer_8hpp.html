Detailed Description

Consumer-side service that translates intra-service messages into NDN Interests and forwards received Data back into the intra-service bus.

The SNDSConsumer listens for SNDS intra-messages (e.g., GET/POST-derived requests, subscription events, temporal queries), converts them into NDN Interests using the parsed-interest utilities, expresses those Interests on the NDN face, and on Data reception publishes results back into the worker queue as SNDS intra-messages.

Key responsibilities:

  • Drive a processing loop in init() that reads messages from the consumer queue.
  • Build canonical NDN names via parsed_interest_name helpers and express Interests.
  • Handle temporal-query flows (direct vs. manifest/metafile modes).
  • Forward registry payloads, GET_BY_* responses, and temporal data back to workers.
