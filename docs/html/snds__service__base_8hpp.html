Detailed Description

Common base class for all SNDS services (HTTP server, Consumer, Producer, DT, Worker).

Provides:

  • A unified logging setup (console + file) using spdlog.
  • NDN primitives (Face, KeyChain, Validator, basic handlers).
  • Lifecycle controls (init, stop).
  • Shared intra-service message queues (static, process-wide).
  • Canonical SNDS naming/config parameters derived from constructor args.
Note
The static message queues are a simple in-process message bus for this prototype; they are shared by all ServiceBase instances. Consider replacing with a real broker or per-service channels if you need isolation or distribution.
