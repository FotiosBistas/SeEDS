Detailed Description

HTTP entry point for SNDS, converting HTTP requests to intra-messages.

Uses cpp-httplib to listen on 0.0.0.0:8080 and expose two handlers:

  • GET / : forwards classified queries to the Worker queue.
  • POST /: forwards classified advertisements to the Digital-Twin queue.

The classification logic is delegated to snds_intra_message::SNDS_INTRA_MESSAGE::infer_type_from_params(), which uses present/absent parameters (from QUERY_PARAM_LIST) plus the HTTP verb to decide the concrete snds_intra_message::SNDS_INTRA_MESSAGE_TYPE.

void SNDSHTTPService::init ( )
overridevirtual

Start the HTTP server (blocking until shutdown).

  • Registers GET / and POST / handlers.
  • For each request:
    1. Extract parameters using the DECLARE_/EXTRACT_ macros from query_params.hpp.
    2. Create an snds_intra_message::SNDS_INTRA_MESSAGE and set the HTTP verb.
    3. Call infer_type_from_params() to classify the message.
    4. Send to the appropriate queue:
      • GET → ServiceBase::v_to_worker
      • POST → ServiceBase::v_to_dt
    5. Wait for a single response from ServiceBase::v_to_service and return its payload.
  • Spawns the cpp-httplib server in a background thread; the main thread polls the ServiceBase::running flag and coordinates shutdown.
Warning
This implementation processes one reply at a time per incoming request and uses a simple wait on ServiceBase::v_to_service. If multiple requests are active concurrently, ensure your queues and workers are provisioned to preserve the expected correlation semantics.
