Detailed Description

Concrete consumer service that bridges SNDS intra-messages to NDN Interests.

Note
Inherits logging, queues, and NDN face from ServiceBase.

◆ init()

void SNDSConsumer::init ( )
virtual

Start the consumer loop.

Repeatedly reads messages from the consumer queue (v_to_consumer). For each message, selects the correct Interest expression path based on the SNDS_INTRA_MESSAGE_TYPE. The loop exits when running (inherited) becomes false or the queue is shut down.

Reimplemented from ServiceBase.

virtual

Data callback for expressed Interests.

Parameters
interestThe original Interest.
dataThe received Data packet.

Decodes payload, parses the carried name back to a ParsedInterestName, and forwards an appropriate SNDS intra-message to the worker queue. Handles:

  • registry payloads,
  • GET_BY_* responses,
  • temporal-query results (direct item vs. metafile manifest expansion).

Reimplemented from ServiceBase.
