Detailed Description

A thread-safe producer-consumer message queue.

The MessageQueue class provides a thread-safe mechanism for producers and consumers to exchange messages. Internally, it uses a std::deque to store messages along with a std::mutex and std::condition_variable for synchronization. A shutdown flag is included to allow the queue to break out of waiting when the service is shutting down.

std::unique_ptr< snds_intra_message::SNDS_INTRA_MESSAGE > MessageQueue::readMessage ( )

Reads a message from the queue.

This function blocks until there is a message available in the queue or until the shutdown flag is set to true. If the shutdown flag is set and the queue is empty, the function returns a nullptr.

Returns
A unique_ptr to a SNDS_INTRA_MESSAGE if available; otherwise, nullptr.

void MessageQueue::shutdown ( )

Signals the queue to shutdown.

This function sets the shutdown flag to true and notifies all waiting threads so that they can exit gracefully even if the queue is empty.
