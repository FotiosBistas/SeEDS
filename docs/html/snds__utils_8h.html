Extracts the value associated with a specific tag from a GET request URL.

The function expects the URL to have the following format: "/tag=value&tag=value&tag=value..."

It searches for "tag=" within the URL, and if found, extracts the substring up to the next '&' (or the end of the URL).

Parameters
urlThe GET request string as a std::string_view.
tagThe tag whose associated value should be extracted, as a std::string_view.
Returns
The value corresponding to the tag. Returns an empty string if the tag is not found.

Computes and returns the scope name for the responsible SNDS node based on the given subscription identifier.

This function computes the responsible node index by hashing the provided subscription identifier using getSNDSNodeForSubscription. It then converts the node index to a string and concatenates it with a provided scope prefix (e.g., "/SNDS_ID_scope_") to form the complete scope name.

std::vector<std::byte> serialize_registry_file_payload ( const std::unordered_set< std::string > &  ids)

Serializes a set of IDs into a binary payload.

The payload is structured as follows: [number_of_ids (2 bytes, big‐endian)] [id1_length (2 bytes, big‐endian)] [id1 bytes...] [id2_length (2 bytes, big‐endian)] [id2 bytes...] ...

  • The first 2 bytes hold the number of IDs (max 65 535).
  • Each ID is preceded by a 2-byte length (max length 65 535).
Parameters
idsAn unordered_set of strings representing the IDs.
Returns
A vector of std::byte containing the binary payload.
Exceptions
std::length_errorif the number of IDs exceeds 65 535 or any ID's length exceeds 65 535.
