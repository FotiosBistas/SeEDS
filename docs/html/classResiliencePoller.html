Detailed Description

Periodically probes a peer node for liveness and state metadata, and pulls patches/snapshots.

The poller runs two lightweight scheduler threads:

  • an "alive loop" that sends GET_RESILIENCE_IS_ALIVE interests with a random nonce,
  • a "meta loop" that sends GET_RESILIENCE_META interests to discover the peer's head {version,hash,ts}.

All network I/O is posted onto the NDN Face's io_context (thread-affine) to keep ndn-cxx happy. When the remote version advances, the poller requests a patch (from last applied → remote head). If a patch cannot be applied (or NACKs/times out), it falls back to fetching a snapshot.

Application code should wire the callbacks to actually apply patches/snapshots to local state. Callbacks are invoked on the Face's io_context thread.
