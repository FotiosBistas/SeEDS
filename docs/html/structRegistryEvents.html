Detailed Description

Event hooks for registry and subscription changes.

This struct aggregates optional callbacks invoked by the producer when the in-memory registry/subscriber state or announcement set changes. Install any subset of these to react to updates (e.g., mirror state elsewhere, update UI, trigger logging/metrics).
