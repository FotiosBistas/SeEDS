Detailed Description

Versioned, canonical JSON store with bounded history and patch generation.

The store maintains:

  • current state_ (canonical JSON),
  • monotonic version_,
  • canonical hash_,
  • a bounded history_ mapping version→state for patch creation.

Use mutate to edit the state in-place or assign to replace it. After each change, version_ is incremented, hash_ recomputed, and the new state is recorded in history_ (trimmed to keep_ entries).
