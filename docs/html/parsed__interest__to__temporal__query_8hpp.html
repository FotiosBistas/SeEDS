temporal_query::TemporalQuery temporal_query_from_interest ( const parsed_interest_name::ParsedInterestName &  pi)
inline

Construct a TemporalQuery object from a parsed NDN Interest.

This function maps fields from a parsed_interest_name::ParsedInterestName into a temporal_query::TemporalQuery. The mapping rules are:

  • pi.name → used as the query's ID (q.id).
  • Each element of pi.params is treated as a raw "key=value" token (percent-decoded before use).
    • "date=<val>" → sets q.date.
    • "timeframe=<val>" → parsed with temporal_query::string_to_timeframe and stored in q.frame.
    • "count=<val>" → sets q.count.
    • "filters=<val>" → parsed with temporal_query::parse_filters and stored in q.filters.
    • Any other parameter or missing ‘’='is stored inq.extras[key] = value`.
Parameters
piParsed Interest name with prefix, id, and parameter tokens.
Returns
A populated temporal_query::TemporalQuery.
Note
The current implementation assumes:
  • pi.prefix denotes the type/service component, but it is not directly used (see commented code).
  • pi.name carries the ID to query.

This mapping is based on conventions. Adjust if your naming scheme differs.
