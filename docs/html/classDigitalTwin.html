Detailed Description

Service that translates intra-messages into NDN advertisements and scope notifications.

Note
Inherits transport queues, logger, and lifecycle controls from ServiceBase.

Handle a BY_ID_ADVERTISEMENT request.

Parameters
idThe object identifier to advertise and scope.
