\hypertarget{md_README_autotoc_md7}{}\doxysubsection{Service}\label{md_README_autotoc_md7}
At runtime, Se\+EDS is a small distributed system composed of five cooperating services that run inside one process (each on its own thread) and talk over in-\/memory message queues. External I/O happens via NDN Interests/\+Data and a tiny HTTP API\+:


\begin{DoxyItemize}
\item SNDSHTTPService\+: small HTTP server (cpp-\/httplib) that turns HTTP GET/\+POST into internal messages.
\item Worker\+: Parses requests, deduplicates, tracks state, aggregates results, and sends responses back to HTTP.
\item SNDSConsumer\+: emits NDN Interests constructed from Worker’s requests, receives Data packets, and forwards payloads back.
\item SNDSProducer\+: answers incoming NDN Interests (publishes Data) and also initiates outbound Interests when needed.
\item Digital\+Twin\+: drives advertisements (by-\/\+ID / by-\/type / scope) and forwards “temporal query” announcements to Producer.
\end{DoxyItemize}\hypertarget{md_README_autotoc_md8}{}\doxysubsubsection{Main Requests}\label{md_README_autotoc_md8}
\hypertarget{md_README_autotoc_md9}{}\doxyparagraph{GET by ID ( Forwarded to the NDN through the temporal query API )}\label{md_README_autotoc_md9}
HTTP receives {\ttfamily GET /?id=$<$ID$>$} (or POST body). It packs params into an intra-\/message and sends to Worker.

Worker\+:
\begin{DoxyItemize}
\item Deduplicates with pending\+\_\+get\+\_\+by\+\_\+id\+\_\+requests (set).
\item Builds an NDN name\+: {\ttfamily /$<$snds\+\_\+prefix$>$/$<$id$>$/get\+By\+ID\+:$<$id$>$} using parsed\+\_\+interest\+\_\+name helpers.
\item Sends a GET\+\_\+\+BY\+\_\+\+ID\+\_\+\+REQUEST message to Consumer.
\end{DoxyItemize}

Consumer\+:
\begin{DoxyItemize}
\item Expresses the NDN Interest. Note that all the interests are forwarded through the temporal query API.
\item On Data\+: forwards payload to Worker as GET\+\_\+\+BY\+\_\+\+ID\+\_\+\+RESPONSE.
\end{DoxyItemize}

Worker\+:
\begin{DoxyItemize}
\item Confirms the ID was pending; clears it; optionally tells Digital\+Twin to erase pending state.
\item Writes the final response to the HTTP queue as TEMPORAL\+\_\+\+QUERY\+\_\+\+RESPONSE (used uniformly for JSON).
\end{DoxyItemize}

HTTP\+:
\begin{DoxyItemize}
\item Waits for one message from the service queue and returns 200 with the payload.
\end{DoxyItemize}\hypertarget{md_README_autotoc_md10}{}\doxyparagraph{GET by TYPE}\label{md_README_autotoc_md10}

\begin{DoxyItemize}
\item Deduplicates with pending\+\_\+get\+\_\+by\+\_\+type\+\_\+requests.
\item Computes $<$\+TYPE$>$\+\_\+registry (configurable postfix).
\item Sends GET\+\_\+\+BY\+\_\+\+TYPE\+\_\+\+REQUEST to Consumer with NDN name\+: {\ttfamily /$<$snds\+\_\+prefix$>$/$<$TYPE$>$\+\_\+registry/get\+By\+Type\+:$<$TYPE$>$} or {\ttfamily /$<$snds\+\_\+prefix$>$/$<$TYPE$>$/get\+By\+Type\+:$<$TYPE$>$} which is equivalent.

The resilience layer keeps a SECONDARY node in sync with a PRIMARY by exchanging tiny JSON envelopes over NDN. It prefers JSON Patch deltas for speed and falls back to full snapshots when needed. Everything is content-\/addressed with a deterministic hash so both sides can prove they agree.\hypertarget{md_README_autotoc_md22}{}\doxysubsubsection{Store (\+PRIMARY)}\label{md_README_autotoc_md22}
Canonical, versioned JSON store with a bounded history. Each change bumps a version, recomputes a canonical hash, and keeps a snapshot for patch generation. Exposes\+:


\begin{DoxyItemize}
\item Meta → \{version, hash\}\+: a lightweight head descriptor for quick “are we in sync?” checks.
\item Patch → \{base\+\_\+version, target\+\_\+version, target\+\_\+hash, ops\} where ops is RFC6902 JSON Patch {\ttfamily (nlohmann\+::json\+::diff(base,target))}. Apply with {\ttfamily json.\+patch(ops)}.
\item Snapshot → \{version, hash, state\}\+: full state transfer for cold start or when a patch isn’t possible.
\end{DoxyItemize}\hypertarget{md_README_autotoc_md23}{}\doxysubsubsection{Mirror (\+SECONDARY)}\label{md_README_autotoc_md23}
Local follower that applies Snapshot or Patch. Validates via canonical hash; on mismatch it logs and normalizes locally (the goal is convergence, not crypto).\hypertarget{md_README_autotoc_md24}{}\doxysubsubsection{Resilience\+Poller (\+SECONDARY)}\label{md_README_autotoc_md24}
A tiny scheduler that probes the PRIMARY and pulls updates. It runs two periodic loops and posts all I/O onto the NDN Face’s io\+\_\+context\+:


\begin{DoxyItemize}
\item Alive loop\+: proves reachability with a nonce echo.
\item Meta loop\+: reads \{version, hash, ts\} and decides whether to fetch a patch or snapshot.
